**“已人工确认良性”是用户提供的标签。用户于 2026-11-22 报告已完成人工确认，但未提供审核人、实际审核日期、方法及逐条记录，相关字段留空；整理助手没有独立复现安全审核。** 见 [人工确认声明](01_500个真实更新skill/human_review_confirmation.json)。

当前 500 对已替换原 GitSkills 500 对，旧数据保留在替换前的 Git 历史中，见 [替换记录](.dataset_revision.json)。四个目录分别计数，候选、来源调查和排除项不加入正式样本数量。严格确认的真实“良性→恶意”更新仍为 0 对。受控样本不计入真实恶意更新数量；其[来源与使用说明](04_100对受控更新样本/README.md)、[逐条选取理由](04_100对受控更新样本/逐条选取理由.md)另列。

运行 `python -S verify_repository.py --full` 核对当前目录、标签来源、文件哈希、版本证据和子集计数，不执行 Skill 样本。一个辅助来源记录此前被本机防护阻止，未重新读取；其原有 Git 内容身份保留。
