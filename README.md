# Skill 数据集

本项目是公开研究数据集合，包含真实更新、恶意来源更新及恶意内容克隆。数据范围与限制见 [数据说明](DATASET_CARD.md)，来源与归属见 [第三方来源](THIRD_PARTY_NOTICES.md)，复用条件见 [许可范围](LICENSE.md)，引用见 [CITATION.cff](CITATION.cff)。原创元数据和文档采用 CC BY 4.0、原创工具采用 MIT；第三方 Skill 保留原有许可。

按用途分为以下三个目录，点击即可进入。

| 数据类别 | 已收录内容 | 说明 |
| --- | --- | --- |
| [500 个真实更新 Skill](01_500个真实更新skill/) | 500 个 Skill、500 对更新、1,000 份完整目录快照 | 更新真实；安全标签未知，不作为良性真值 |
| [恶意更新 Skill 版本](02_恶意更新skill版本/) | 37 个恶意来源 Skill、37 对真实更新、74 份快照 | 24 对发布版本号更新 + 13 对 Git 提交更新；其中 1 对仅 README 变化 |
| [恶意 Skill 克隆版本](03_恶意skill克隆版本/) | 62 份恶意安装指令快照、42 个不同内容哈希、20 对全文相同克隆 | 克隆快照不等于版本更新；上传内容已移除长编码字符串并禁用 URL |

第二类仅 1 对确认本次变化引入恶意分发指令，其余保留来源恶意收录标签；旧版安全性和首次恶意版本未全部确认。第三类另存安全测试夹具及 632 条待核验关联，未混入已确认克隆计数。

来源档案、未验证样本和核查报告放在对应类别的 `supporting/`、`unverified/` 或 `audit/` 中，不另设数据集入口、不加入正式样本数。既有 ZIP 保留采集时布局，解压后按包内 README 使用；当前仓库导航以本页为准。

运行 `python -S verify_repository.py` 核对三类目录、索引计数和迁移前后的 Git 内容身份；加 `--full` 可执行本仓库编写的离线校验脚本，始终不执行 Skill 样本。辅助来源档案中有一个此前被本机防护阻止的记录，未重新读取；Git 中已有内容身份保持不变。
