# 曖昧パターン集

ユーザー発話がこれらに該当したら **必ず深掘り**。

## 抽象語単独

| NG表現 | 深掘り例 |
|---|---|
| 大変 | 「具体的にはどの工程が一番しんどい？」 |
| 面倒 | 「どの作業で手が止まる？」 |
| つらい | 「何に時間取られてる？」 |
| いろいろ | 「代表的なやつ1個教えて」 |
| 難しい | 「どこで詰まってる？」 |

## 頻度のぼかし

| NG表現 | 深掘り例 |
|---|---|
| よく | 「週何回くらい？」 |
| たまに | 「月1？月2？」 |
| 結構ある | 「直近1ヶ月だと何回？」 |

## 主語・目的語不明

| NG表現 | 深掘り例 |
|---|---|
| それが大変 | 「"それ"ってどの作業？」 |
| そこが問題 | 「どの工程のこと？」 |

## 影響のぼかし

| NG表現 | 深掘り例 |
|---|---|
| 時間かかる | 「1回あたり何時間？」 |
| 負担 | 「誰が何時間分くらい使ってる？」 |
| 困ってる | 「具体的に何が起きてる？」 |
